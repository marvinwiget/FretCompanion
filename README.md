# Fret Companion

Fret Companion is a Flask application that helps guitarists find songs from their listening history that match their current guitar skills and preferences.

The application uses ListenBrainz to retrieve a user's listening history and will analyze songs based on factors such as difficulty, techniques, chords, and tuning. These requirements can then be compared against a user's guitar profile to recommend songs that are a good fit to learn next.

## Tech Stack

- Python
- Flask
- ListenBrainz API
- Jinja2
- Requests

## Status

Fret Companion is currently in early development.
